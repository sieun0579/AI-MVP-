# 3단계: 실행용 Context 검색

## 목적

로컬 LLM을 연결하기 전에 질문과 관련된 회사 Context를 검색하고, 근거가 없을 때는 답변을 생성하지 않는 검색 계층을 만든다.

## 작동 방식

1. `runtime_documents.json`만 읽는다.
2. 긴 본문을 제목과 줄 경계로 나눠 검색 조각을 만든다.
3. 한국어 단어와 글자 단위 특징을 사용해 관련도를 계산한다.
4. 기준을 넘긴 원문 조각만 출처와 함께 반환한다.
5. 검색 결과가 없으면 `확인 가능한 데이터가 없습니다.`를 반환한다.

평가용·개발용 JSON은 색인 입력으로 받을 수 없다. 검색 결과에는 생성된 답변이 없으며, `text` 필드는 변환된 실행용 원문에 실제로 존재하는 문자열이다.

## 실행 방법

색인 생성:

```bash
uv run python scripts/build_search_index.py
```

검색:

```bash
uv run python scripts/search_context.py "야외 행사 순간풍속 중단 기준"
```

결과 수 제한:

```bash
uv run python scripts/search_context.py "개인정보 보관 기간" --top-k 3
```

## 현재 한계

- 아직 자연어 답변을 작성하지 않는다.
- 사용자의 역할에 따른 세부 권한 필터는 다음 기능 단계에서 적용한다.
- 동의어와 문맥 이해는 키워드 기반이므로 이후 로컬 임베딩 또는 로컬 LLM 연결로 보완한다.
