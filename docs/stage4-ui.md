# 4단계: 브라우저 챗봇 화면

## 목적

검증된 실행용 Context 검색 기능을 브라우저 화면에서 직접 시험한다. 이 버전은 로컬 LLM을 연결하지 않으며 검색 원문을 답변 근거 카드로 표시한다.

## 실행

```bash
uv sync --group dev
uv run streamlit run app.py
```

터미널에 표시된 로컬 주소를 브라우저에서 열고 질문을 입력한다.

## 화면 구성

- 질문 입력창
- 사용자·시스템 대화 기록
- 관련 Context 원문 카드
- 문서 ID, 상태, 적용일, 관련도
- Notion 원문 링크
- 데이터 없음 안내
- 대화 기록 초기화

## 응답 원칙

- 검색된 원문을 새 답변처럼 재작성하지 않는다.
- 실행용 검색 색인만 사용한다.
- 근거가 없으면 `확인 가능한 데이터가 없습니다.`를 표시한다.
- `이거`, `저번 행사` 같은 지시어의 대화 맥락 해석은 아직 지원하지 않는다.
- 숫자 검색은 현재 키워드 일치이며 예산 필드 조건 검색은 아직 지원하지 않는다.
